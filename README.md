# sampatti-setu
 Smart Asset Matching, Police-inventory &amp; Audit Tracking Technology Interface

A unified digital platform connecting citizens, police stations and Malkhana records.

Digitizes police-property/Malkhana records into a searchable inventory.

Allows citizens to report Lost / Stolen / Found items and track their cases.

Uses AI-powered image matching to identify possible matches between found/lost objects and recorded property.

Sends match notifications to the citizen, finder and concerned police authorities.


How It Addresses the Problem

Reduces dependence on manual Malkhana record searching.

Connects lost-item complaints with recovered/recorded property.

Provides a transparent digital case-tracking workflow.

Helps police identify potential matches faster.


Innovation & Uniqueness

Digital Malkhana + Citizen Reporting + AI Matching in one ecosystem.

Multi-angle object images improve visual comparison.

Combines visual similarity and object-detail verification rather than relying only on appearance/color.

Creates an auditable digital trail from complaint → match → verification → recovery.
